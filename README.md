# P. Gutt Representações - Corporate Website

[![Website](https://img.shields.io/badge/Website-pgutt.com.br-00599E?style=for-the-badge&logo=googlechrome&logoColor=white)](https://pgutt.com.br)

A professional corporate platform built for **P. Gutt Representações e Comércio de Equipamentos, Ltda.**, a sales representation firm established in 1985 that specializes in representing international manufacturers of industrial equipment and engineered materials.

---

## Tech Stack

<a href="https://skillicons.dev">
  <img src="https://skillicons.dev/icons?i=python,django,html,css,js,heroku,cloudflare,git" />
</a>

* Back-End and Framework: Python & Django
* Database: PostgreSQL 
* Deployment and Hosting: Heroku
* DNS & Security: Cloudflare

---

## Features

* Catalog Database: Dynamic database structure allowing visitors to explore and access/download product catalogs from various international partner companies.
* Responsive Design: Clean layout adapted for desktop and mobile devices.
* Contact and Representation Inquiries: Integrated communication form for direct client outreach.
